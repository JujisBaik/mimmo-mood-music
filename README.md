# 🎵 MiMo Mood Music Generator

A **FREE** & **absurd** music generator that creates songs based on your mood using Xiaomi MiMo technology!

> 🎯 **Project for Xiaomi MiMo 100T Creator Incentive Program**

---

## ✨ Features

- 🎭 **Mood Selection**: Choose from Happy, Sad, Angry, Excited, or Chill
- 🎵 **Absurd Lyrics**: Generate hilarious lyrics based on your mood
- 🎹 **Simple Music**: Play melody that matches the mood
- 💯 **100% FREE**: No API keys required, completely free to use!
- 📱 **Responsive**: Works on desktop and mobile

---

## 🚀 Quick Start

### Local Development

```bash
# Clone the repository
git clone https://github.com/JujisBaik/mimmo-mood-music.git
cd mimmo-mood-music

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

This project was created for the **Xiaomi MiMo 100T Creator Incentive Program** with these goals:

1. **Absurd & Fun**: Generates hilarious songs based on moods
2. **100% FREE**: No paid APIs or services required

---

## 🎵 How It Works

1. User selects a mood (Happy, Sad, Angry, Excited, Chill)
2. System generates absurd lyrics based on the selected mood
3. Tone.js creates a simple melody matching the mood
4. User can play the song and enjoy!
